# Архитектура Claude Brainrot

Решение от 2026-11-04. Две независимые реализации для Claude Code и Codex desktop на Windows. Каждая использует подтверждённую поверхность и способ установки своего хоста. Эксперименты размещены в `plugins/claude` и `plugins/codex`. [Локальные прототипы](PLUGIN-PROTOTYPES.md) используют skill Claude и MCP Apps ресурс для Codex. Desktop-воспроизведение остаётся **UNVERIFIED**. Общий код выделяется только при доказанной пользе для обеих реализаций.

## Интерфейс

Ориентир по эскизу — вертикальные слоты слева и справа от чата и горизонтальный слот под чатом. Все три ролика видны одновременно. Если хост управляет раскладкой, проверить одну встроенную панель с тремя видео и описать отличие. Если подходящего встроенного варианта нет, этот target блокируется. Для внешнего окна требуется отдельное согласование. Правки файлов хоста и внедрение в его DOM исключены.

## Что проверяет Phase 0

[Текущие результаты на Windows и оставшиеся проверки](research/embedded-ui-phase0.md).

- **Claude Code.** Проверить Mods Pane в Code tab на установленном Windows-хосте, доступные примитивы рендера и поддержку локального видео. Сверить экспортированные типы runtime и ближайшее к slash-команде действие. Документация Mods сама по себе не подтверждает видео. [Claude Mods](https://code.claude.com/docs/en/plugins/mods/reference)
- **Codex.** Проверить встроенную conversation panel в режиме Codex, в том числе применимость MCP Apps к этой поверхности, ограничения sandbox/CSP, локальные файлы, mute/autoplay и сохранение панели при смене чата. Документация ChatGPT UI сама по себе не подтверждает этот сценарий в Codex. [Plugin Extensions](https://developers.openai.com/plugins/build/extensions) · [MCP UI](https://developers.openai.com/plugins/build/chatgpt-ui)

Фиксировать версию хоста, официальный контракт, фактический результат на desktop, доступную раскладку и входное действие. Если доступно только действие плагина, skill или кнопка панели, выбрать ближайший поддерживаемый вызов и явно указать, нужен ли начальный model turn. Поддержка трёх локальных потоков пока не подтверждена ни для одного target.

## Воспроизведение и медиа

Панель владеет тремя проигрывателями, состоянием переключения и таймером. `/brainrot` показывает или скрывает UI, `off` останавливает видео и таймер, `next` переключает вручную, `shuffle` включает случайный порядок. Базовый интервал автопереключения — около 60 секунд. Playback, локальные controls и таймер работают без дополнительных модельных вызовов. MCP допустим только при подтверждённой необходимости для встроенного UI. Постоянный фоновый сервис и отслеживание активности агента вне текущего плана.

При первой настройке загрузить ролики из проверенных источников и использовать локальный кеш при следующих запусках. Для каждого файла записать источник, лицензию, право на загрузку и требуемую атрибуцию. Стартовые категории — Subway Surfers, soap cutting, carpet cleaning / pressure washing. Minecraft parkour опционален. Если разрешённая автоматическая загрузка недоступна, показать причину и предложить импорт собственных или иных разрешённых файлов. Поддерживаемые форматы и способ доступа к кешу определяются проверками хоста.

## Релизы

Два отдельных артефакта и независимые проверки готовности: **Brainrot for Claude Code** и **Brainrot for Codex**. У каждого свои инструкции установки и удаления, поддерживаемые версии и ограничения UI. Блокер одного хоста не является проверкой второго. [Этапы и зависимости](../ROADMAP.md)

Прежний оконный прототип описан в отчётах [Electron bootstrap](PHASE1-BOOTSTRAP.md), [локальный импорт](PHASE1-MEDIA.md) и [воспроизведение](PHASE1-PLAYBACK.md). Его стек и оконный сценарий не входят в архитектуру пакетов.
