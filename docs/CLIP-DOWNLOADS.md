# Поиск и загрузка клипов

```powershell
node scripts/find-clips.mjs "pressure washing" 3
```

Укажи категорию и число роликов от 1 до 10. Поиск принимает названия на английском, например `Subway Surfers`, `Minecraft parkour`, `soap cutting`, `carpet cleaning`, `pressure washing` и `satisfying`. Он запрашивает [Wikimedia Commons](https://www.mediawiki.org/wiki/API:Imageinfo/en), фильтрует оригиналы по источнику, лицензии CC0 / CC BY / CC BY-SA, атрибуции, формату и размеру. Загрузчик сверяет SHA-1 из Commons, проверяет контейнер и декодирует видеопоток. Поддерживаются исходные MP4 и WebM. Другие форматы пропускаются.

Пути к файлам и автоматически созданному каталогу выводятся в консоль. В каталоге есть источник, автор, атрибуция, лицензия, SHA-256 и локальный путь. Если выдача частичная, команда показывает фактическое число. При нулевой выдаче она пишет пустой каталог и завершает работу с кодом 2. Запросы по неподдержанным категориям могут давать нулевую выдачу.

Для воспроизведения выбери скачанные файлы из `.TMP/brainrot/clips` в виджете. Он случайно перемешивает порядок, показывает три разных файла и переключает их каждые 60 секунд. Доступ к виджету в Codex Desktop остаётся **UNVERIFIED**.

## Дополнительный режим для заранее проверенных источников

Из корня проекта запусти `node scripts/download-clips.mjs .TMP/approved-clips.json`. Нужны Node.js, FFprobe и FFmpeg в PATH. Загрузчик печатает пути к клипам в `.TMP/brainrot/clips`. Эти файлы можно выбрать в виджете Brainrot. Повторный запуск проверяет SHA-256 и использует кеш офлайн.

Каталог доверенных источников хранится в `.TMP`. Пример структуры с условными значениями:

```json
{
  "allowedHosts": ["media.example"],
  "assets": [
    {
      "download": "https://media.example/clip.mp4",
      "source": "https://creator.example/clip",
      "license": "https://creator.example/download-permission",
      "creator": "Имя автора",
      "category": "soap cutting",
      "permission": "Автор разрешает автоматическую загрузку по этому URL для локального просмотра",
      "mime": "video/mp4",
      "sha256": "<64 строчных hex-символа из проверенного источника>"
    }
  ]
}
```

Добавляй запись после проверки происхождения, условий использования, права на автоматическую загрузку и атрибуции. Поля каталога фиксируют доказательства, а SHA-256 проверяет точные байты. Принимаются прямые HTTPS-ссылки без редиректов, MP4 и WebM до 32 МиБ и 120 секунд. Файл попадает в кеш только после проверки контрольной суммы, контейнера и полного декодирования видеопотока.

Обычная ссылка на пост TikTok не содержит прямого файла. [Display API](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-object) предоставляет ссылки для просмотра и встраивания. Если у поста доступно [Save video](https://support.tiktok.com/en/using-tiktok/exploring-videos/video-downloads?lang=ar), можно сохранить его штатно и выбрать файл в виджете. Для автоматической загрузки нужен отдельный разрешённый автором прямой источник. Автоматический поиск на этом этапе использует Commons. Для отдельных TikTok-постов поддерживается штатное сохранение и локальный импорт.
