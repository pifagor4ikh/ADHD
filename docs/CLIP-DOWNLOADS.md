# Загрузка клипов в локальный кеш

Из корня проекта запусти `node scripts/download-clips.mjs .TMP/approved-clips.json`. Нужны Node.js, FFprobe и FFmpeg в PATH. Загрузчик печатает пути к клипам в `.TMP/brainrot/clips`. Эти файлы можно выбрать в виджете Brainrot. Повторный запуск проверяет SHA-256 и использует кеш офлайн.

Каталог доверенных источников хранится в `.TMP`. Пример структуры с условными значениями:

```json
{
  "allowedHosts": ["media.example"],
  "assets": [
    {
      "download": "https://media.example/clip.mp4",
      "source": "https://creator.example/clip",
      "license": "https://creator.example/download-permission",
      "creator": "Имя автора",
      "category": "soap cutting",
      "permission": "Автор разрешает автоматическую загрузку по этому URL для локального просмотра",
      "mime": "video/mp4",
      "sha256": "<64 строчных hex-символа из проверенного источника>"
    }
  ]
}
```

Добавляй запись после проверки происхождения, условий использования, права на автоматическую загрузку и атрибуции. Поля каталога фиксируют доказательства, а SHA-256 проверяет точные байты. Принимаются прямые HTTPS-ссылки без редиректов, MP4 и WebM до 32 МиБ и 120 секунд. Файл попадает в кеш только после проверки контрольной суммы, контейнера и полного декодирования видеопотока.

Обычная ссылка на пост TikTok не содержит прямого файла. [Display API](https://developers.tiktok.com/docs/en/tiktok-api-v2-video-object) предоставляет ссылки для просмотра и встраивания. Если у поста доступно [Save video](https://support.tiktok.com/en/using-tiktok/exploring-videos/video-downloads?lang=ar), можно сохранить его штатно и выбрать файл в виджете. Для автоматической загрузки нужен отдельный разрешённый автором прямой источник. Проверенного стартового каталога пока нет.
