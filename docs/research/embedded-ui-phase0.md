# Phase 0 — встроенные поверхности Windows

Срез на 2026-11-04. Уточнение по прямому запросу реестра в #14: Windows 24H2, build 26100.9711; прежнее указание 25H2 / 26200 не подтверждено. Инвентаризация приложений обнаружила Claude Desktop и запущенное приложение ChatGPT с идентификатором пакета Codex. Версии CLI — Claude Code 2.1.212 и codex-cli 0.166.0-alpha.5.1. Версия пакета Codex Desktop уточнена в #14: `26.1027.6604.0`; версия Claude Desktop отдельно не подтверждена.

## Claude Code в Claude Desktop

[Mods Reference](https://code.claude.com/docs/en/plugins/mods/reference) и [Draw in the interface](https://code.claude.com/docs/en/plugins/mods/interface) описывают рендер через UI-примитивы Mods. Документированного элемента для видео в проверенной справке не найдено. Возможность открыть Pane сама по себе не подтверждает доступ к видеодекодеру или локальным файлам из панели.

**Наблюдение.** Claude Desktop был закрыт. Запуск через Computer Use вернул `Computer Use was not approved to use Claude`. Типы и видео в установленном Code tab не проверены.

**Следующая проверка.** В Code tab записать версию Desktop и проверить доступность `/plugin-types`. В экспортированных типах проверить `ui.render`, `Pane`, доступные элементы и поддерживаемые способы вызова. При наличии документированного примитива для медиа показать один собственный локальный тестовый клип в Pane, затем проверить размещение трёх клипов. Если типы и документация не дают поддерживаемого пути к видео, зафиксировать блокер для этой версии.

## Codex в ChatGPT Desktop

**Актуальный результат #14:** [подробный отчёт](codex-phase0-issue14.md). Обнаружен провайдер `Codex MCP Apps` без открытых вкладок. Локальный stdio smoke прошёл, рендер и воспроизведение в Desktop остаются **UNVERIFIED**. Исследование завершено с блокером runtime-проверки; Phase 1 не открыта.

[OpenAI Docs о MCP UI](https://developers.openai.com/plugins/build/chatgpt-ui) описывает встроенный iframe в ChatGPT. [Quickstart](https://developers.openai.com/plugins/build/app-quickstart) отдельно описывает сервер для ChatGPT и Codex и пример UI в ChatGPT. Применимость примера к установленному режиму Codex требует проверки. Историческую ссылку на conversation panel не считаем подтверждением трёх слотов вокруг чата.

**Наблюдение.** Окно обнаружено в инвентаризации. Computer Use исключает автоматизацию UI ChatGPT Desktop. Установка или запуск тестового UI в режиме Codex не проверялись.

**Следующая проверка.** На отдельном локальном чате Codex записать версию Desktop и вручную вызвать тестовый инструмент с документированным MCP Apps UI resource, начиная с карточки с текстом. Критерий первого шага — карточка появляется внутри окна и принимает локальное действие. Если она доступна, проверить воспроизведение собственного тестового клипа из локального кеша разрешённым способом, затем три потока в одной панели, mute, loop и поведение при смене чата. Записать фактический способ вызова и ограничения CSP. Если карточка не появляется, отдельно записать, вернул ли инструмент ресурс и показал ли хост ошибку.

## Решение

Phase 0 остаётся открытой для обоих хостов. Локальное прототипирование разрешено до проверки Desktop. Подтверждение встроенного видео остаётся критерием готовности каждого плагина. Временные экспорты и доказательства хранить в `.TMP`; в отчёт переносить версии, результат и ограничения без содержимого чатов.
