name: brainrot-media-workflow
description: Audit video rights and plan or verify local video acquisition and FFmpeg processing for Brainrot.
---

Read `references/media-checklist.md` before acquiring media. Use `docs/research/media.md` as a dated starting point, not as a license grant. Check existing skills and installed tools before adding a downloader or dependency.

Do not equate a public video, an embedded player, or a platform-wide license with permission for automated downloading and redistribution. Record rights for each exact asset; prefer CC0 or a directly granted download license. Import user recordings for game categories when reuse is unclear. Never bypass access controls.

Transcoding, trimming or removing audio does not create redistribution rights. Check permission for the automated access method separately from permission to use the file.

Phase 0 is planning only. In authorized acquisition phases, stage downloads and transformations in project `.TMP`, validate before atomic cache promotion, and keep media out of Git. Reuse cached verified assets; on source failure use another approved source or honestly label a generated fallback. A fallback is not authentic category footage.

Do not promise first-run coverage of three authentic categories until three suitable assets and usable download methods are verified. Stop release readiness at that gate instead of quietly substituting unrelated videos.
