# Verification layers

1. Phase 0: skill frontmatter; local reference links; exact canonical/discovery content; sync idempotence, drift detection and invalid-input behavior; architecture evidence and unresolved experiments.
2. Engine: three independent local streams, muted startup, loop and decode errors, pause/resume/next/shuffle, import and deterministic scheduling; offline test with zero model calls.
3. Sources: lawful per-asset provenance, full decode and integrity, bounded downloads, cold/warm/offline cache and fallback visibility.
4. Hosts: exact installed desktop version/OS, native-panel media spike, installation/removal, trust prompt, actual activity events, multiple chats, interrupted turn, crash/restart and manual override.
5. Release: clean Windows install/uninstall, packaged codecs and local paths, resize/DPI/multiple monitors, dependency and media notices, no bundled secrets/media caches.

Write screenshots and test reports under `.TMP`. Record durable conclusions without private transcripts in project docs. Never count an unavailable environment as a passed check.
