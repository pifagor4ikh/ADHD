# Claude Brainrot

Проект двух независимых плагинов: **Brainrot for Claude Code** и **Brainrot for Codex**. Каждый планируется выпускать отдельным релизным пакетом. Собственный код — MIT.

После вызова `/brainrot` или ближайшего поддерживаемого действия в окне хоста появляются три видео. Ориентир — два вертикальных слота по бокам чата и один горизонтальный снизу. Если хост даёт только одну встроенную панель, проверим, помещаются ли в неё три ролика. Отдельное окно требует отдельного согласования.

Ролики воспроизводятся одновременно, по кругу и без звука по умолчанию. Запланированы `off`, `next`, `shuffle` и автопереключение примерно раз в минуту. При первой настройке плагин загружает разрешённые ролики в локальный кеш. Если подходящего источника нет, пользователь может импортировать свои файлы. Целевые категории — Subway Surfers, soap cutting, carpet cleaning / pressure washing, опционально Minecraft parkour.

**Статус.** Phase 0 предстоит подтвердить встроенную поверхность в каждом desktop-хосте. Предыдущий [Electron bootstrap](docs/PHASE1-BOOTSTRAP.md) — исторический эксперимент. Доступны [локальные прототипы и инструкции](docs/PLUGIN-PROTOTYPES.md). Воспроизведение в desktop-хостах — **UNVERIFIED**.
